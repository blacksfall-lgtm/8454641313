# SRP 调度的原生证据

此页是静态分析说明，不能替代完整源码。直接调用按机器指令地址列出；条件分支、平台分支、异步队列、历史帧与间接调用必须结合汇编还原。编译器合并了部分相同函数，因此某个地址可能有多个候选符号，不能只凭其中第一个名字认定调用语义。

- ScsRenderPipelineAsset.CreatePipeline：RVA 0x2385FF0。先调用 Validate；验证失败返回 null；成功路径从 asset 读取 resources / config / mediumManager / decalManager / heatmapSettings，创建 ScsRenderPipeline 并保存到 _renderPipeline。它确实需要资源、配置和场景管理器，不是换一个 Shader 就能启动。
- ScsRenderPipeline：相机 Render 与 RenderSceneCamera 的方法地址及调用见 RuntimeNavigation/ScsRenderPipeline.md。
- SceneRenderPipeline.EncodePreGeometryRenderingAlgorithmsSerial：RVA 0x2384A20。原生指令中依次存在 DownsampleSceneDataPass、ClusteredLightListBuildPass、DepthPrepass、DepthPyramidStage、GlobalIlluminationStage、LightingStage、DecalStage、VolumetricStage、FirmamentStage 的调用。此处的“依次存在”是静态调用点顺序，不表示每帧每个分支必定全部执行。
- EncodePreGeometryRenderingAlgorithmsAsync：RVA 0x2384640。存在 SetExecutionFlags、ExecuteCommandBufferAsync、MakeGraphicsFence 和 WaitOnAsyncGraphicsFence；恢复时不能把异步路线直接当作串行逐帧调用。
- VolumetricStage.EncodeVolumetricPasses：RVA 0x238DD50。包含 GenerateDensityBufferLitPass.Encode 和 CameraScatteredLightIntegrationPass.Encode，以及结果 SetGlobalTexture；对应密度生成与散射积分。
- PostProcessStage.EncodePostProcessing：RVA 0x2381B70。包含 DepthOfFieldAlgorithm.Encode、EncodeAntiAliasing 和 EncodeFinalPostProcessing。
- EncodeFinalPostProcessing：RVA 0x2381670。包含 ColorGradingLutPass.Encode、BloomPass.Encode、FinalBlitPass.Encode 和目标纹理/临时资源处理。
- PixelizationPass 的资源绑定、绘制和方法地址见 RuntimeNavigation/PixelizationPass.md。不要只凭类名推断它在全部路线中的准确插入点，应追踪 SceneRenderPipeline 和 GeometryRenderingStage 的实际调用及分支。

原生函数存在 chained unwind 代码片段。例如 CreatePipeline 的第一段只到 0x2386027，后续构造和返回逻辑在另两段。本包已依据 PE .pdata 的 UNW_FLAG_CHAININFO 合并这些片段；NativeMethods/*.bin 是片段顺序拼接，地址必须按 runtime-method-index.json 的 segments 重定位，不能把整个 bin 当作一个连续 RVA 段。
